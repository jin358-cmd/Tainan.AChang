## 兩批共用資料契約

| 欄位 | 規則 |
| --- | --- |
| `source_batch_id` | 穩定批次 ID，批次修訂時不以當前時間重生 |
| `source_stop_id` | 每筆穩定 ID，同一來源站點重複匯入時不變 |
| `service_id` | 穩定服務路線 ID，例如「週三 + A」；不使用車牌作識別 |
| `weekday` | `星期三`／`星期五`；缺值不得啟用 |
| `route` | `A`／`B`；缺值不得啟用 |
| `start` | 必填 `HH:mm` |
| `end` | 可空；不得自行推算 |
| `name` | 站名；有來源衝突時保留原文並候審 |
| `truck` | 可空；不得虛構車牌 |
| `source_order` | 同批原始順序，時間相同時作穩定次序 |
| `review_required` | `true` 時可顯示候審，但不得進入排班 |
| `review_note` | 保留各來源差異，不以推測覆寫 |
| `service_notice` | 例外提示：遇國定假日、颱風假停收 |

防重複鍵為 `source_batch_id + source_stop_id`。同鍵且 payload 相同時視為幂等重試；同鍵但 payload 不同時必須中止並要求審核，不可靜默覆寫。
