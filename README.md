# Tainan.AChang｜永康十里正式 PWA v1.0.2

以既有 v0.4 的地圖／服務分區／跟巡排班／名冊四分頁為基礎。

## 本次修正
- 訪客可查看公開四分頁框架及公開清運資料；真實名冊僅在管理員驗證後讀取。
- 管理員在名冊使用「＋新增會員」，先新增正式人員，再向管理員會員授權服務開通。任何一段失敗會明確通知，避免未完成卻顯示成功。
- 首次登入且裝置獲管理員核准後，已安裝 PWA 可直接啟動本人工作頁，後續從 HttpOnly、Secure、SameSite=Strict Cookie 安全恢復工作階段；不儲存電話密碼至 localStorage。
- 活動期間的刷新工作階段採 90 天滑動使用期限。登出、裝置停用／撤銷或超過有效期均需重新授權登入。
- 若不同瀏覽器／首次安裝成為不同的 App 儲存空間，需對新裝置完成一次授權。

## 安全界線
正式志工個資不納入公開 GitHub。服務端依 Supabase Auth、裝置授權與 RLS 驗證，使用者不能透過前端跳過權限。公開地圖不表示已獲授權讀取私密名冊。API 路徑不得被 Service Worker 快取。

## 尚待真實裝置端驗證
正式管理員首次登入、已核准志工重新開啟 PWA、Chrome 安裝及 iOS 主畫面儲存空間差異、跨裝置完成任務雲端回讀。
